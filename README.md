Entry for the [make.fun bounty "The Best Meal You Ever Had"](https://make.fun/bounty/u-pangg7-the-best-meal-you-ever-had-a3ac0f85) ($2).

`main.ts` writes a single sentence (at most 200 characters) about the best meal
ever had to `/output/entry.txt`. One named dish, one named place, one time, one
price, one burned tongue — and a second bowl anyway.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/best-meal-out node main.ts
cat /tmp/best-meal-out/entry.txt
```
